# Face 3D — Football Life 27

Ce dossier est dédié à la création d'un véritable modèle 3D du visage de référence, destiné à être préparé pour le pipeline de faces PES 2021 / Football Life 27.

## Objectif
Créer une tête 3D reconnaissable et fidèle aux photos, puis préparer sa géométrie, ses UV et ses textures avant toute conversion vers le format du jeu.

## Références photo
Les références actuellement disponibles dans le dépôt sont :
- `../20261110_221139.jpg` — vue de face.
- `../20261110_221314.jpg` — vue trois-quarts.
- `../20261110_221347.jpg` — vue de profil.

Vérifier les noms et l'orientation des photos avant le travail de sculpture. La vue de profil a été repérée dans le dépôt, mais doit encore être inspectée visuellement dans Blender.

## Étapes de production
1. Vérifier les trois références et leurs proportions.
2. Construire le blockout de la tête dans Blender.
3. Comparer face, trois-quarts et profil, puis corriger les volumes.
4. Faire la retopologie et préparer les UV.
5. Créer les textures de peau, cheveux et barbe.
6. Préparer le modèle pour le pipeline PES 2021 / Football Life 27.
7. Tester en jeu et corriger les écarts.

## État actuel
**Préparation uniquement.** Aucun modèle final ni fichier compatible avec le jeu n'est encore produit. Une image de rendu ou un maillage générique ne sera pas considéré comme une livraison finale.

## Critère de validation
Le modèle ne sera validé que si les vues de face, trois-quarts et profil correspondent suffisamment aux références. La ressemblance prime sur le style artistique.
